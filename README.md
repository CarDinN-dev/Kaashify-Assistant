# Kaashify Assistant v0.1.44-preview.2

Download [Kaashify-Setup.exe](Kaashify-Setup.exe) and open it on Windows x64 to update Kaashify Assistant. The installer uses your existing Kaashify profile.

In Settings, add an OpenAI API key and turn on **OpenAI voice** under **Voice**. OpenAI receives reply text for speech synthesis. Local speech plays if the API is unavailable. Choose your reasoning and screen models in the existing model settings.

Turn on **Hands** and **Wake commands** in the same Voice card. Tap your talk shortcut, then say one phrase such as “Hey Kaashify, open Notepad and type hello.” Kaashify closes the microphone after it hears a command or after 30 seconds. Review drafts and forms before you send or submit them.

This unsigned preview is based on [7c04b20](https://github.com/CarDinN-dev/Kaashify-Assistant/commit/7c04b20d8e9a051cf8392d931e2ccee73376809a). Live OpenAI speech and Windows workflow checks are pending.
